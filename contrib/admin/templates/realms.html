How these fields are used
After a client authenticates, realmd decides which address to hand back by checking whether the client's IP falls inside localAddress masked by localSubnetMask. Clients inside that subnet get localAddress; everyone else gets address. So address is the internet-facing one and localAddress is for your LAN.

address may be a hostname: realmd resolves it server-side and re-reads the whole realm list every 20 seconds, so a dynamic-DNS change is picked up on its own with no restart. The catch is that a hostname which does not resolve causes realmd to drop the realm from the list entirely, so confirm DNS is live before saving one.

port is shared by both LAN and internet clients and must match the port the world server actually listens on, which is why the world port cannot be remapped by NAT alone.
